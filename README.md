## List of Programs

### Basic Java Programs (25)
1. **AreaOfCircle.java**: Area of circle (`Area = PI * r^2`)
2. **AreaOfTriangle.java**: Area of triangle (`Area = 0.5 * b * h`)
3. **AreaOfRectangle.java**: Area of rectangle (`Area = l * b`)
4. **AreaOfIsoscelesTriangle.java**: Area of isosceles triangle (`(b * sqrt(4*a^2 - b^2)) / 4`)
5. **AreaOfParallelogram.java**: Area of parallelogram (`Area = b * h`)
6. **AreaOfRhombus.java**: Area of rhombus (`Area = (d1 * d2) / 2`)
7. **AreaOfEquilateralTriangle.java**: Area of equilateral triangle (`(sqrt(3) / 4) * a^2`)
8. **PerimeterOfCircle.java**: Perimeter / circumference of circle (`2 * PI * r`)
9. **PerimeterOfEquilateralTriangle.java**: Perimeter of equilateral triangle (`3 * a`)
10. **PerimeterOfParallelogram.java**: Perimeter of parallelogram (`2 * (a + b)`)
11. **PerimeterOfRectangle.java**: Perimeter of rectangle (`2 * (l + b)`)
12. **PerimeterOfSquare.java**: Perimeter of square (`4 * a`)
13. **PerimeterOfRhombus.java**: Perimeter of rhombus (`4 * a`)
14. **VolumeOfCone.java**: Volume of cone (`(1/3) * PI * r^2 * h`)
15. **VolumeOfPrism.java**: Volume of prism (`baseArea * h`)
16. **VolumeOfCylinder.java**: Volume of cylinder (`PI * r^2 * h`)
17. **VolumeOfSphere.java**: Volume of sphere (`(4/3) * PI * r^3`)
18. **VolumeOfPyramid.java**: Volume of pyramid (`(1/3) * baseArea * h`)
19. **CurvedSurfaceAreaOfCylinder.java**: Curved surface area of cylinder (`2 * PI * r * h`)
20. **TotalSurfaceAreaOfCube.java**: Total surface area of cube (`6 * a^2`)
21. **FibonacciSeries.java**: Prints first n terms of Fibonacci sequence
22. **SubtractProductAndSum.java**: LeetCode 1281 - Difference between product and sum of digits
23. **FactorsOfNumber.java**: Prints all factors of a number using loops
24. **SumUntilZero.java**: Reads numbers until 0 and prints total sum
25. **LargestUntilZero.java**: Reads numbers until 0 and prints largest number

### Intermediate Java Programs (27)
1. **Factorial.java**: Calculates factorial `n!`
2. **ElectricityBill.java**: Calculates electricity bill based on consumption slabs
3. **AverageOfNNumbers.java**: Calculates the average of N user-entered numbers
4. **DiscountOfProduct.java**: Calculates discount amount and final selling price
5. **DistanceBetweenPoints.java**: Euclidean distance between two coordinates
6. **CommissionPercentage.java**: Calculates commission percentage
7. **Power.java**: Computes `base^exponent`
8. **DepreciationOfValue.java**: Depreciated asset value over time
9. **BattingAverage.java**: Cricket batting average calculation
10. **CalculateCGPA.java**: Calculates CGPA and equivalent percentage
11. **CompoundInterest.java**: Compound interest and final amount
12. **AverageMarks.java**: Calculates total and average marks of subjects
13. **AdditionOfTwoNumbers.java**: Adds two numbers
14. **SumOfNNumbers.java**: Calculates sum of N numbers
15. **ArmstrongNumber.java**: Checks if a number is an Armstrong number
16. **NcrAndNpr.java**: Computes permutations (`nPr`) and combinations (`nCr`)
17. **ReverseString.java**: Reverses an input string
18. **PalindromeNumber.java**: Checks if an integer is a palindrome
19. **FutureInvestmentValue.java**: Future investment value calculation
20. **HcfOfTwoNumbers.java**: Highest Common Factor (GCD) using Euclidean algorithm
21. **LcmOfTwoNumbers.java**: Lowest Common Multiple via HCF
22. **VowelOrConsonant.java**: Checks whether a character is vowel or consonant
23. **PerfectNumber.java**: Checks if a number is a perfect number
24. **LeapYear.java**: Determines whether a given year is a leap year
25. **SumOfDigits.java**: Sum of digits of an integer
26. **KunalAugustDays.java**: Counts number of even days in August (15 days)
27. **SumOfNumbersCategories.java**: Sum of negative, positive even, and positive odd numbers until 0 is entered

## How to Compile and Run

To compile any program:
```bash
javac basic/AreaOfCircle.java
java -cp basic AreaOfCircle
```

Or for intermediate programs:
```bash
javac intermediate/Factorial.java
java -cp intermediate Factorial
```
